# 🛡️ Telhawk Galen — Developer Beta Community

### AI-Powered Security Testing for Vibe Coders & Developers

Welcome to the official Telhawk Galen Developer Beta Community!

Galen is designed to help developers identify security
vulnerabilities in their applications using AI-assisted workflows.

Whether you're building with Codex, Claude Code, Cursor,
or another AI coding assistant, Galen is designed to make
security testing easier and more accessible.

You don't need to be a cybersecurity expert to get started.

---

## 🚀 Getting Started

Getting started with Galen is simple.

1. Download the Galen ZIP file from the official beta
   distribution link.
2. Open your project using your preferred AI coding assistant.
3. Tell your AI where you saved the Galen ZIP file.
4. Ask your AI to inspect the documentation, help set up
   Galen, and run a security analysis.

Your AI assistant can guide you through the process.

**Important:** Review any commands your AI proposes.
Do not allow it to install additional software or modify
your application without your approval.

👉 [Getting Started & Installation Guide](https://github.com/telhawk-systems/galen-community/discussions/2)
